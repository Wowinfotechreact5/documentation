Troubleshooting helps you fix common issues in WOWagent.

Use this page when setup, integrations, website scans, chatbot, forms, billing, or account access are not working as expected.

<Tip>
  Looking for a quick answer? Check the [FAQ](/faq) first.
</Tip>

## A Feature Is Locked

If a feature is locked, go to Integration Center:

[https://portal.wowagent.ai/website/integrations](https://portal.wowagent.ai/website/integrations)

Common reasons features are locked:

- Widget is not verified
- Required integration is not connected
- DNS setup is incomplete
- Publishing setup is incomplete
- Current plan does not include the feature
- Free trial access is limited

Complete the missing setup and try again.

## Website Domain Is Not Accepted

If WOWagent does not accept your domain, check the format.

Correct format:

**example.com**

Do not use:

- `https://example.com`
- `www.example.com/contact`
- `example.com?source=ad`

Also check that:

- The domain is not already added.
- The website is live.
- DNS is active.
- SSL is valid.
- There are no extra spaces.

For full domain rules, see [Add Your Website](/add-your-website).

## Website Scan Failed

A website scan can fail when:

- Website is temporarily down
- DNS is still updating
- SSL certificate is invalid
- Hosting server is blocking requests
- Firewall or CDN blocks automated checks
- Website URL is incorrect

Fix the website issue and run the scan again.

Website Overview URL:

[https://portal.wowagent.ai/website](https://portal.wowagent.ai/website)

## Chatbot Is Not Showing On Website

Check these points:

- Widget script is installed
- Script is installed on the correct website
- Integration Center shows widget verified
- Website cache is cleared
- Browser cache is cleared
- Correct website is selected in WOWagent

Chatbot Management URL:

[https://portal.wowagent.ai/ai-agent](https://portal.wowagent.ai/ai-agent)

Integration Center URL:

[https://portal.wowagent.ai/website/integrations](https://portal.wowagent.ai/website/integrations)

For step-by-step install and fix instructions, see [Install Widget](/install-widget). If the widget still does not appear, create a support ticket.

## Assistant Gives Wrong Answers

If the assistant gives wrong or incomplete answers, update the Knowledge Base.

Check:

- Business profile
- Business hours
- Products and services
- FAQs
- Website pages
- Uploaded documents
- Bot boundaries

Knowledge Base URL:

[https://portal.wowagent.ai/ai-agent/knowledge-base](https://portal.wowagent.ai/ai-agent/knowledge-base)

After updating, test the assistant again in the Sandbox. For tips on writing better answers, see [Knowledge Base](/knowledge-base).

## Leads Are Not Appearing

If leads or enquiries are missing, check:

- Website form is active
- Widget is installed correctly
- Form was submitted successfully
- Correct website is selected
- Correct workspace is selected
- Integration setup is complete

Customer Enquiries URL:

[https://portal.wowagent.ai/ai-agent/leads](https://portal.wowagent.ai/ai-agent/leads)

Or, in the left menu, go to **Forms and Enquiries** and click **Customer Enquiries**.

Forms URL:

[https://portal.wowagent.ai/forms](https://portal.wowagent.ai/forms)

Submit a test enquiry and check again.

## SEO Data Looks Missing

SEO data may be missing if:

- Website was recently added
- Scan has not completed
- Search integration is not connected
- Website blocks crawlers
- Domain has very little public data
- Integration Center setup is incomplete

SEO Intelligence URL:

[https://portal.wowagent.ai/seo-research/domain](https://portal.wowagent.ai/seo-research/domain)

Complete setup and run scans again.

## Workspace Or Permission Issue

If you cannot open a page, your account probably does not have permission for it.

Check:

- You are in the correct workspace
- Your invited account has accepted access
- Your role allows access to that module
- The workspace owner has given correct permissions

User Management URL:

[https://portal.wowagent.ai/user-management](https://portal.wowagent.ai/user-management)

Ask the workspace owner to review your access.

## Session Expired Or Redirected To Login

If WOWagent sends you back to the login page, your session has probably expired. Log in again.

Login URL:

[https://portal.wowagent.ai/login](https://portal.wowagent.ai/login)

If this repeats:

- Clear browser cache
- Clear site data for WOWagent
- Try another browser
- Contact support

## When To Contact Support

Create a Support Ticket when:

- You cannot complete onboarding
- Integration verification fails repeatedly
- Website scan fails after retry
- Widget does not appear
- Leads are missing
- Billing status looks wrong
- You cannot access your workspace
- You see repeated errors

Support Tickets URL:

[https://portal.wowagent.ai/support-tickets](https://portal.wowagent.ai/support-tickets)

## What To Include In A Support Ticket

Include:

- Website domain
- Your workspace name
- Page where the issue happened
- What you clicked
- Screenshot if possible
- Expected result
- Actual result

This helps support solve the issue faster.
