## Website Health

Website Health helps you understand the operational condition of your selected website.

You can use it to review:

- Website availability
- Uptime status
- Server response
- Response time
- Performance signals
- SSL status
- DNS status
- Website health trends
- Recent issues or alerts

## Date Range

Website Health may include date filters.

Use the date filter when you want to check website health for a specific time period.

For example, you can review:

- Last 7 days
- Current week
- Specific date range
- Recent issue period

Use **Reset** to return to the default date range.

## PDF Report

If available, use the PDF download option to export a website health report.

- Website maintenance proof
- Developer handoff

## Cyber Security

Cyber Security helps you review website safety and security issues.

You can use it to check:

- Security score
- Malware scan status
- SSL issues
- Security headers
- Vulnerabilities
- Incidents
- Risk level
- Recommendations

## When To Check Health And Security

Check these pages when:

- Your website feels slow
- Visitors report website errors
- SSL shows a warning in the browser
- You recently changed DNS or hosting
- You installed or updated website plugins
- You want to review website safety
- You need a report for your team or client
- You notice traffic or lead drops
- A browser marks your website as unsafe

## What To Fix First

Prioritize issues in this order:

1. Website down or unreachable
2. SSL expired or invalid
3. Malware or critical security warning
4. DNS misconfiguration
5. Broken redirects or blocked pages
6. SEO-impacting technical issues
7. Performance warnings

## If You See A Security Warning

<Warning>
  Do not ignore security warnings.
</Warning>

First, review the warning details.

Then contact your developer, hosting provider, or support team if you are unsure how to fix it.

If the warning is related to WOWagent setup, create a Support Ticket from the panel.

Support Tickets URL:

[https://portal.wowagent.ai/support-tickets](https://portal.wowagent.ai/support-tickets)
